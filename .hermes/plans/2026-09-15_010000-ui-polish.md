# SignFlow — UI polish + "make it better" pass

**Goal:** Elevate the whole app's visual craft — real type pairing, refined tokens, proper motion — with the Avatar sign player as the hero surface.

**Pre-flight findings (verified):**
- Next 16 App Router, React 19, plain CSS tokens in `app/globals.css` (user's locked dark design language: `#0a0a0f` bg, `#1c1c2e` cards, white text, `#4f9cff` accent)
- Fonts: system stack only (`ui-rounded, -apple-system`) — no display identity
- Motion: none (no library), `prefers-reduced-motion` already honored
- Buttons/cards have partial states only; nav is plain pills

**Constraints:** keep routes, keep the user's dark theme anchor values, no new deps beyond `next/font` (built in). Honest-copy rules: no invented metrics.

---

## Phase A — Design system (`app/globals.css`, `app/layout.tsx`)

1. Fonts via `next/font/google`: **Bricolage Grotesque** (display: headings, brand), **Geist** (body/UI), **Geist Mono** (outlier, ≤2 slots: letter chips + caption — letters are the content). `display: swap`.
2. Tokens: keep `--bg/--card/--card2/--text/--accent` anchors exactly; tint borders/muted slightly cooler-blue (anchor hue); add `--ease-out/in/in-out`, `--dur-micro/short/long`, elevation steps (cards get lighter, not darker, per level).
3. Buttons: full states — hover `translateY(-1px)` 150ms `--ease-out`, active press 80ms, instant focus ring, disabled. Primary button keeps accent but flatter (accent as highlight, less fill noise).
4. Nav: brand wordmark in display face; active link accent-underlined pill; backdrop blur kept.
5. Cards: tighter borders, one elevation, heading hierarchy (display face on h2).

## Phase B — Avatar page as hero (`app/avatar/page.tsx`)

1. Stage layout: avatar canvas in a framed "stage" card with soft radial depth (not gradient-banner slop — a barely-there vignette), caption overlaid at bottom.
2. Transport bar: icon+label buttons (Sign/Pause/Resume/Replay/Stop), Loop as a switch, speed slider. Grouped in one row that wraps cleanly at 375px.
3. Letter chips: mono face, 2xl, active chip gets accent border+fill pop (`scale 1 → 1.06 → 1`, 120ms), click replays letter (existing logic).
4. One orchestrated page-load stagger (reveal, ≤400ms total). No other scroll motion.
5. Phrase chips restyled as quiet suggestions.

## Phase C — Home page (`app/page.tsx`)

1. Typographic hero: display-face headline ("Say it with your hands"), subline, primary CTA → /live, secondary → /avatar.
2. Functional demo instead of decoration: a "now spelling" mono strip that types H-E-L-L-O letter by letter client-side (reduced-motion: static), showing what the app does.
3. Collapse the three prose cards into: recognition summary + privacy + honest limits, tighter copy, fewer repeated hedges.

## Phase D — Verify & ship

- `npm test`, `npx tsc --noEmit`, `eslint`, `npm run build`
- Headless Chrome screenshots: `/` and `/avatar?text=HI` at 375px and 900px; inspect with vision
- Commit per phase, push, verify origin/main advanced. (6am cron for word-sign phases 3–5 remains scheduled — it pulls before starting.)

**Risks:** `next/font` needs network at build (fallback: keep system stack, note it). Do not touch the 6am cron's scope.
