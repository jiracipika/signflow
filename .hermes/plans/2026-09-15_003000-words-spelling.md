# SignFlow — Words & Spelling Experience

**Goal:** Make the output side of SignFlow (avatar signing words + fingerspelling) genuinely nice: natural letter-to-letter flow, real J/Z strokes, synced caption, real playback controls — then expand word-sign coverage and practice around it.

**Current state (verified Sep 15):** `lib/signs/avatar-engine.ts` interpolates rest→letter→rest per letter (choppy, not how fingerspelling flows), J/Z use a generic sinusoidal wiggle, playback in `app/avatar/page.tsx` is fire-and-forget with only a speed slider (no pause/replay/loop/scrub, no letter-synced caption). `components/SignAvatar.tsx` loops motion frames at 45ms and already draws a stylized hand with trails. 26 mean poses in `public/models/asl-poses-v1.json` (A–Z, real dataset means). Taught dynamic signs replay when the typed text starts with their name.

**Tech stack:** Next 16 App Router, React 19, TS, canvas avatar, node --test + tsc --noEmit. No new deps.

## Phase 1 — Playback engine v2 (execute now)

Rewrite `lib/signs/avatar-engine.ts`:

- `export const FRAME_MS = 45` (unify with SignAvatar's playback tick; old HANDS=24 was inconsistent).
- New return type:
  ```ts
  export type LetterSpan = { letter: string; start: number; end: number };
  export type SignSequence = {
    frames: Pose[][];
    caption: string;
    spans: LetterSpan[];                                  // frame ranges per letter
    words: { text: string; start: number; end: number }[]; // frame ranges per word
  };
  ```
- Letter-to-letter flow: transition directly prev-letter → next-letter (7-frame smoothstep), rest pose ONLY at word boundaries (longer dwell). No more return-to-neutral between letters — that's the single biggest realism win.
- Real J/Z strokes: move the whole hand along the true stroke path (J: pinky-traced down-then-hook; Z: index-traced right / diagonal-down-left / right) using eased waypoint paths in hand-space offsets. Replaces the sinusoidal wiggle.
- Keep `neutralPose`, strip non A-Z chars, space → word break.
- Keep the old `spellSequence(text, poses, opts)` signature shape so the call site stays simple.

Files: `lib/signs/avatar-engine.ts` (rewrite), `tests/avatar-engine.test.ts` (new: frame counts positive, spans contiguous/monotonic, word gaps longer than letter gaps, J/Z strokes translate the pinky/index beyond shape hold, caption preserved).
